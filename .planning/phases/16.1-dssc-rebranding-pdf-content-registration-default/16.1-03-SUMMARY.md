## Decisions Made

- **Feature flag over deletion:** Per D-14's requirement that "the SP option be restorable later by flipping a single module-level boolean constant back to true — no JSX rewrite needed", implemented as a render-gate constant rather than JSX deletion. This ensures the restore path requires only one line change with zero architectural impact.
- **Preserved useState and submit logic:** The `useState<"DSI" | "SP">("DSI")` default (line 14) and the submit body's `participant_type: participantType` (line 27) remain unchanged. With the toggle hidden, `participantType` never changes from "DSI", so registration always submits DSI without additional logic.
- **Wrapped entire toggle block:** The label, button group, and description text are all wrapped together under the feature flag, keeping the conditional boundary clear and maintainable.
