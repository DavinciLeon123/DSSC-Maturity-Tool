## Technical Decisions / Implementation Notes

1. **Logo Asset Naming:** Followed D-01's intended naming (`logo-dssc-color.png`, `logo-dssc-white.png`) — the plan allows executor discretion on naming.

2. **Font Replacement Strategy:** Applied 'Open Sans' to all Rubik occurrences in these files, since none of them contain display-level h1/h2/h3 headings that would warrant Jost (per D-04's headline/body split). All styled elements are nav links, buttons, labels, or small display text. Jost will be applied in later phases when larger headlines are introduced.

3. **Hero Gradient Collapse:** Per D-02 ("one primary blue, not a two-tone navy gradient"), changed `linear-gradient(135deg, #006004f 0%, #00006b 100%)` to flat `linear-gradient(135deg, #008ecf 0%, #008ecf 100%)` — effectively `background: #008ecf` for clarity and maintenance.

4. **RGB Decomposition:** To handle both hex and rgba forms of the old colors, used RGB decomposition:
   - #06004f = rgb(6, 0, 79) → replaced `rgba(6,0,79,` with `rgba(0,142,207,` (RGB for #008ecf = 0, 142, 207)
   - #399e5a = rgb(57, 158, 90) → replaced `rgba(57,158,90,` with `rgba(118,184,42,` (RGB for #76b82a = 118, 184, 42)

5. **No Backend Changes:** Per plan scope, no backend files (report.html, report_generator.py, reports.py, auth.py, main.py) were modified — that work is 16.1-02's responsibility.
