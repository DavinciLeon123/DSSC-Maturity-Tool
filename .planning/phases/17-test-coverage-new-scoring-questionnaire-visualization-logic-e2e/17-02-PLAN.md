From `frontend/src/hooks/useDebouncedSave.ts` (exact current shape — DO NOT modify this file):
```typescript
export type SaveState = "idle" | "saving" | "retrying" | "saved" | "failed" | "rate-limited";
const DEBOUNCE_MS = 1500;
const RETRY_DELAYS_MS = [1000, 2000, 4000];  // 3 retry attempts after the first try

export function useDebouncedSave(
  initiativeId: number,
  onStateChange: (questionId: string, state: SaveState) => void
): {
  schedule: (questionId: string, categoryId: string, score: number) => void;
  flush: (questionId: string) => Promise<void>;
  flushAll: () => Promise<void[]>;
};
```
`saveWithRetry` internally: on each attempt calls `onStateChange(id, attempt === 0 ? "saving" :
"retrying")`, then `await saveAnswer(initiativeId, questionId, {question_id, category_id, score})`.
On success: `onStateChange(id, "saved")`. On a caught error: if `err.response.status === 429`,
`onStateChange(id, "rate-limited")` and RETURN immediately (no retry consumed — non-escalating).
Otherwise, if this was the last attempt (`attempt === RETRY_DELAYS_MS.length`, i.e. the 4th
attempt / 3rd retry), `onStateChange(id, "failed")`. Otherwise `await new Promise(resolve =>
setTimeout(resolve, RETRY_DELAYS_MS[attempt]))` then loops to the next attempt.
`schedule()` debounces via `setTimeout(..., DEBOUNCE_MS)`, last-write-wins per `questionId`.
