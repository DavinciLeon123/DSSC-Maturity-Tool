## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-16-01 | Information Disclosure (IDOR) | assessment_id query param on report endpoints | high | mitigate | resolve_report_assessment re-derives ownership server-side (initiative.user_id == current_user.id) and returns 404 (not 403) on any non-owned/non-existent assessment_id; assessment_id coerced to positive int by FastAPI (V4/V5). |
| T-16-03 | Elevation of Privilege | admin report-view bypass | medium | mitigate | Admin access granted only via current_user.role == "ADMIN" inside the ownership guard; the owner-scoped check is not weakened for non-admins (D-07). |

Any HTML-context user text (initiative name) flows through Jinja2 autoescape, never into the `| safe` SVG string (RESEARCH Security Domain). |
| T-16-SC | Tampering | package installs | low | accept | No new package introduced this phase. |
