# Phase 16.2: Content & UX Updates — Frontpage/About Rebrand Copy, Assessment Intro Texts & Question Grouping - Context

**Gathered:** 2026-08-03
**Status:** Ready for planning

<domain>
## Phase Boundary

The homepage, About page, and assessment wizard reflect the new DSMA copy, structure,
and grouping specified in `Teksten MAMI Tool.pdf`, so the tool's content and question
flow match the finalized wording before test-coverage and security-hardening work
begins. Five deliverables: (1) homepage copy + brand alignment, (2) About page copy +
brand alignment, (3) a wizard welcome screen before question 1, (4) a per-dimension
intro paragraph on each of the 6 dimension pages, (5) grouping the 52 questions into 16
named subsections.

</domain>

<decisions>
## Implementation Decisions

### Homepage & About page — color/brand alignment (target: dssc.eu)
- Reference: https://dssc.eu/ — match its visual language, not just "some colors"
- Font: switch to "Jost" (variable font) **app-wide**, not just these two pages
- Self-host Jost locally (`@font-face` + `.ttf`, mirroring dssc.eu's own approach)
  rather than pulling from Google Fonts CDN — reference copy already downloaded to
  `reference-assets/Jost-VariableFont_wght.ttf` (weight range 100-900; dssc.eu also
  serves an italic variant at `/fonts/Jost-Italic-VariableFont_wght.ttf` if italics are
  needed later)
- Hero background: match dssc.eu **exactly** — white/paper base (`#fff`) with a subtle
  135deg diagonal gradient wash
  `linear-gradient(135deg, rgba(118,184,42,0.06) 0%, rgba(0,142,207,0.10) 60%, rgba(255,255,255,0) 100%)`,
  not a solid color block
- Main heading/body text color: dssc.eu's "ink" `#1c2025` (near-black), not pure
  `#000` — this is what the user's "black" request maps to
- Optional accent: dssc.eu applies a green→blue gradient-clip effect to part of its H1
  text (`linear-gradient(135deg, var(--dssc-green) 0%, var(--dssc-blue) 100%)` clipped
  to text) — consider applying to an accent phrase in the homepage heading, consistent
  with "match exactly"
- Footer background: dssc.eu's dark navy `#0f1c2b`, white/light text
  (`rgba(255,255,255,0.85)`)
- Logo: replace with the actual DSSC logo pulled from dssc.eu (not just resize the
  Phase 16.1 asset) — color version for header/light backgrounds, white version for
  footer/dark backgrounds. Both already downloaded at full source resolution
  (2600×1515) to `reference-assets/dssc-logo-color.png` and
  `reference-assets/dssc-logo-white.png`
- Logo sizing: header logo 75px tall, footer logo 50px tall (dssc.eu's own values)
- Broader color pass, not just buttons — headers, backgrounds, accents all in scope
- Centralize colors into shared tokens (`theme.ts`/`globals.css`) while touching these
  files, rather than continuing the current hardcoded-inline-hex-per-file pattern

### Assessment welcome screen
- A real step in the wizard flow — "step 0" before the Governance category, not a
  modal/overlay
- Shown on every fresh assessment start (new draft or retake) — not shown when
  resuming an in-progress draft partway through
- Sits **outside** the StepPills sidebar / progress navigation — not counted as a pill
  or in "Question X of Y"
- One-way: once the user advances to Governance, there's no in-flow "back" to the
  welcome screen
- Copy: full "Voorblad questionnaire" text in `16.2-SOURCE-CONTENT.md` section 4
  (Welcome / What you will assess / What you will receive / Before you start / Time
  required)

### Question subsection grouping (16 subsections across 6 dimensions)
- Sub-header style: small eyebrow label (small-caps/uppercase + subtle divider), not a
  full `<h4>`-weight heading — shouldn't compete with the dimension's own `<h3>` title
- Always fully expanded — no accordion/collapse behavior
- "Question X of Y" counter stays dimension-wide (unchanged) — subsections are a
  purely visual/organizational label layered on top, not a new counting unit
- StepPills sidebar stays dimension-only — subsections are not nested into it
- Exact Q-range → subsection-name mapping (verified against
  `config/dssc-questionnaire.json`) is in `16.2-SOURCE-CONTENT.md` section 5

### Dimension intro text (6 paragraphs, one per dimension)
- Rendered in a distinct styled box (not plain text under the `<h3>`) — visually
  separated from the subsection labels/questions below
- Shown every time that dimension's page is viewed — no dismiss/collapse
- Typography distinct from question text (muted color and/or smaller size) — reads as
  framing/context, not a question
- Copy: exact text in `16.2-SOURCE-CONTENT.md` section 3 (items 14-19)

### Claude's Discretion
- Exact placement of the dimension-intro box relative to the subsection eyebrow labels
- Whether the dimension-intro box reuses the existing white rounded-card pattern
  (`WizardPage.tsx`/`StepPills.tsx`) or a new lighter tint variant
- How broadly to adopt the rest of the dssc.eu token set (spacing/radius/shadow scale)
  beyond the colors/font/logo explicitly decided above
- Exact mechanics of centralizing colors into `theme.ts`/`globals.css` (variable
  naming, whether antd's `ThemeConfig` also gets updated)

</decisions>

<code_context>
## Existing Code Insights

### Reusable Assets
- `frontend/src/components/questionnaire/WizardPage.tsx` (L422-429) — existing white
  rounded-card style (`borderRadius:16px`,
  `boxShadow:'0 2px 12px rgba(0,142,207,0.06)'`) — best template for the welcome
  screen and the dimension-intro styled box
- `StepPills.tsx` (L22-33) — same card pattern, second reference point
- Warning/error banner color patterns already in `questionnaire.tsx`/`WizardPage.tsx`
  — reference if the intro box wants a tinted-background treatment

### Established Patterns
- Colors are hardcoded inline hex per-file today (no shared token usage in
  `index.tsx`/`about.tsx`/`WizardPage.tsx`) — `theme.ts` (antd `ThemeConfig`, still
  named `mamiTheme`) and `globals.css` CSS vars (`--color-navy`/`--color-green`/
  `--color-blue`/etc.) exist but aren't consistently consumed. The "centralize into
  tokens" decision means routing these files through those shared definitions instead
  of continuing the inline pattern.
- The wizard already renders one dimension per page (`categoryIndex` state in
  `WizardPage.tsx`) — the welcome screen slots in as a step before `categoryIndex 0`,
  reusing existing step-advance machinery rather than a new mechanism.
- No subsection/group concept exists in `frontend/src/lib/questionnaire.ts`'s
  `Category`/`Question` types or in `config/dssc-questionnaire.json` — a subsection
  field/lookup needs to be added. Research/planning should decide: extend the config
  with a `subsections` array per category, or keep the Q-range→name mapping as a
  static frontend lookup table (the mapping itself is already verified against the
  live config in `16.2-SOURCE-CONTENT.md`).

### Integration Points
- `frontend/src/routes/index.tsx` — homepage, single-file inline-styled component
- `frontend/src/routes/_app/about.tsx` — About page, uses antd `Card`
- `frontend/src/routes/_app/questionnaire.tsx` — wizard route/wrapper, mounts
  `<WizardPage>`
- `frontend/src/components/questionnaire/WizardPage.tsx` — dimension page rendering,
  category title at L439-450, question list L494-505
- `frontend/src/lib/theme.ts`, `frontend/src/styles/globals.css` — shared color token
  sources to route through
- `config/dssc-questionnaire.json` — live 52-question/6-category config

### dssc.eu reference values (fetched directly from the live site, 2026-08-03)
- Brand colors: `--dssc-blue:#008ecf` `--dssc-green:#76b82a` `--dssc-indigo:#50568e`
  `--dssc-yellow:#fbbc43` `--dssc-slate:#627179` (plus 80/60/20/08 tint variants of
  each)
- Text: `--dssc-black:#111315` `--dssc-ink:#1c2025` (`fg-1`, used for main
  headings/body) `--fg-2:#3d444b`
- Backgrounds: `--dssc-white:#fff` `--dssc-paper:#fafbfc` `--bg-dark:#0f1c2b` (footer)
- Gradient: `linear-gradient(135deg, var(--dssc-green) 0%, var(--dssc-blue) 100%)` —
  used both as a low-opacity background wash over the hero and as a text-clip accent
  on headline copy
- Font: `"Jost", "Helvetica Neue", Arial, sans-serif` — self-hosted variable font
  (`/fonts/Jost-VariableFont_wght.ttf`, weight range 100-900); reference copy saved to
  this phase's `reference-assets/`
- Logo: header 75px tall (color version), footer 50px tall (white version) — both
  downloaded to `reference-assets/` at full source resolution (2600×1515)
- Note: `dssc.eu`'s own current homepage is a lightweight "we're ramping up, full site
  lands later this year" holding page — the values above (colors, font, logo, header/
  footer treatment) are stable brand elements, but there's no full page layout to
  mirror beyond the hero/header/footer already captured.
