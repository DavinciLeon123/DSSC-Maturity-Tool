Apply the copy mapping table above verbatim (do not paraphrase). Alongside the copy changes, make
these color/logo adjustments so the page matches dssc.eu's visual language, not just its words:

1. **Hero section background**: replace the current solid
   `background: 'linear-gradient(135deg, #008ecf 0%, #008ecf 100%)'` (both stops are the same
   color — a flat block, not a real gradient) with:
   `background: 'linear-gradient(135deg, rgba(118,184,42,0.06) 0%, rgba(0,142,207,0.10) 60%, rgba(255,255,255,0) 100%), #fff'`
   This changes the hero from a solid blue band to dssc.eu's white/paper base with a subtle
   diagonal green→blue wash.

2. **Hero logo**: the hero currently shows `logoWhite` (the white logo variant) — appropriate on a
   solid dark-blue background. Now that the hero background is white/light, a white logo would be
   invisible. Swap to `logoSrc` (the color variant) at the same size it currently renders. This is
   a direct, load-bearing consequence of change #1, not optional.

3. **Hero heading/subheading text color**: the `<h1>`/`<p>` currently inherit `color: 'white'` from
   the section wrapper (appropriate for a dark hero). Set the `<h1>` color explicitly to `#1c2025`
   (ink) and the `<p>` subheading to `#3d444b` (fg-2) — remove the section-level `color: 'white'`
   now that the background is light.

4. **Optional gradient-clip accent** (locked decision, dssc.eu itself does this): wrap the phrase
   "Data Spaces Maturity Assessment" (or a reasonable substring of the new `<h1>` text) in a `<span>`
   using the gradient-clip technique shown in `<interfaces>` above, so part of the heading reads in
   the green→blue gradient the way dssc.eu's own H1 does.

5. **Hero secondary CTA ("Create an account")**: currently `background: 'transparent'`,
   `color: 'white'`, `border: '1px solid rgba(255,255,255,0.4)'` — invisible against the new light
   background. Restyle for a light background: `border: '1px solid rgba(0,142,207,0.4)'`,
   `color: '#008ecf'`, background stays transparent. **Do not change this button's text** — per
   CONTEXT.md's resolved research question, "Create an account" has no corresponding source-doc row
   and stays as-is; only its visual treatment changes.

6. **Hero primary CTA ("Start the assessment")**: keep its existing green-background/white-text
   styling — it already has sufficient contrast against the new light hero background. Only update
   its text per the copy table.

7. **Public header logo sizing**: change from `style={{ width: '76px', height: 'auto' }}` to
   `style={{ height: '75px', width: 'auto' }}` — dssc.eu's own header logo height is 75px; the
   current code sizes by width, dssc.eu sizes by height.

8. **Closing banner section background**: the current
   `background: 'linear-gradient(90deg, rgba(118,184,42,0.07) 0%, rgba(118,184,42,0.07) 100%), white'`
   has two identical gradient stops (a flat tint, not a real gradient — the same anti-pattern as the

   the equivalent literal value) for visual consistency across the page, per CONTEXT.md's "broader

9. Leave the "How it works" step-card styling (green icon squares, card borders/shadows) and all
