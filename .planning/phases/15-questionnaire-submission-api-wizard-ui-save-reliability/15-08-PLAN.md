<objective>
Close the single blocking gap from 15-VERIFICATION.md (2026-07-26, status: gaps_found, 5/6 truths): `submit_initiative` freezes a permanent `dimension_scores` snapshot without first verifying the questionnaire is complete. Add the missing `assert_assessment_complete` completeness gate to `submit_initiative`, mirroring the exact pattern every sibling scoring/reporting endpoint already uses (`scoring.py:50`, `reports.py:117,171,194,217,246,277`), so a partially-answered draft (e.g. 1 of 52 questions) can no longer be submitted (HTTP 200) and permanently locked as a garbage version (`overall_average: 0.07`, 5 of 6 categories at `0.0`) with no correction path short of a destructive full retake.

Purpose: This directly defends the phase goal's wording — "every **full** completion creates a new, **permanently preserved** assessment version" — whose implicit corollary is that an incomplete completion must not be permanently preservable. Defends the practical trustworthiness of HIST-02 and honors the cross-cutting SCOR-04 completeness precondition ("scores are only computed once the full questionnaire is 100% answered") for the new submit-time snapshot code path 15-07 introduced.

Output: The completeness gate in `submit_initiative`, a new 422-regression test, and the update to the one pre-existing test that will otherwise break once the gate exists. No new production symbols are created — this modifies an existing endpoint.

Scope fence: This plan MUST NOT reopen or modify anything else from 15-06 (retake endpoint) or 15-07 (frozen-snapshot mechanism, `dimension_scores` column, migration `k2b3c4d5e6f7`, `_to_summary`). Those are independently re-verified sound. Keep this surgical: the gate, its test, and the one pre-existing test that needs updating.
</objective>
